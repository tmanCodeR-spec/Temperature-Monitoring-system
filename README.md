# Temperature-Monitoring-system
The project is based on system that displays real-time temperature using the Atmega238p and LM35 sensor

## Objectives
- To display the temperature read by the LM35 sensor
- Convert the Analogue Input from the analogue input from the LM35 sensor to digital output
- Use scaling techniques to ensure that that the temperature read by the LM35 matches the one on the 7-segment displays

## Components Used
- LM35 temperature sensor
- Atemga328p
- Two 7-segments displays
- 14 220-ohm resistors

## Features
- Real-time temperature monitoring
- LCD temperature display
- ADC interfacing
- Embedded programming
- Proteus simulation

## Tools Used
- Atmel Studio
- Proteus

## Simulation
Project includes a Proteus simulation of the project as a complete system

## Skills Demonstrated

- Embedded Systems
- Sensor Interfacing
- ADC Interfacing
- LCD Programming
- Embedded C
- Circuit Simulation using Proteus
